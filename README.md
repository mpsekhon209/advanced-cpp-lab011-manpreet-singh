# Lab 11 — Maps and Associative Lookup

## Course
CS 20 — Advanced Programming with C++

## Objective
This lab focuses on implementing a map, also known as a dictionary or associative array, which stores key-value pairs and supports efficient lookups by key.

## Required tasks
Students must implement a custom `Map` abstraction that supports:

- insertion of key-value pairs;
- lookup by key;
- updating values;
- removal of entries;
- duplicate prevention;
- listing of keys and values;
- ordered behavior if the design requires sorting.

## Important note
This starter project intentionally includes stubs for the required methods. Students must complete the implementation and justify the chosen design.
